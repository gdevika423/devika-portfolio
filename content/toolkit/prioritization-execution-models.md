## Prioritization & Execution Models

**Context:** Documentation and knowledge system initiatives competing for limited team capacity.  
**Focus:** Structured decision-making for prioritization and execution.

### Purpose

The goal is to move from reactive task handling to deliberate execution based on impact, effort, and strategic value.

### Core Decision Factors

Typical prioritization criteria include:

- user impact
- business importance
- urgency
- dependency risk
- implementation effort
- scalability value

### When it is used

These models are useful when:

- multiple documentation initiatives compete for resources
- roadmap decisions need stronger logic
- teams need better execution discipline
- stakeholders need visibility into trade-offs

### Outcome

These models help teams focus on the highest-value work and execute with more consistency and less ambiguity.
